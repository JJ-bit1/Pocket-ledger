# Pocket Ledger

A full-stack personal finance tracking web application. 

## Features
- User Authentication (JWT & Bcrypt)
- Add, Edit, Delete Expenses
- Set Monthly Budgets
- Privacy Mode (Hide Amounts)
- Dynamic Theming (Change colors and currency via Admin Panel)

## Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express, TypeScript
- **Database:** SQLite
